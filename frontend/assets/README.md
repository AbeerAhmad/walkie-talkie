# Assets Folder

This folder contains app icons and splash screens for your Walkie Talkie app.

## Required Assets

For a production app, you'll need to add the following files:

- `icon.png` - App icon (1024x1024px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `splash.png` - Splash screen image (recommended 1284x2778px)
- `favicon.png` - Web favicon (48x48px)

## Quick Setup

You can use the default Expo assets by running:

```bash
expo init --template blank
```

Then copy the assets folder from the newly created project.

Or create simple placeholder images:
1. Use any online icon generator
2. Create solid color images with the app name/logo
3. Use tools like Figma, Canva, or Adobe Illustrator

## Recommended Tools

- [Figma](https://figma.com) - Free design tool
- [App Icon Generator](https://appicon.co/) - Generate all required icon sizes
- [Expo Icon Guidelines](https://docs.expo.dev/guides/app-icons/)

For now, the app will work without these files, but you'll see warnings in the Expo console.
